Em poucos minutos

Instale e escolha o que ler.

1

Instale o clinews

Baixe pela Snap Store ou use o comando ao lado.

2

Adicione suas fontes

Escolha sugestões por assunto ou cole o endereço do seu site.

3

Leia no terminal

Atualize as notícias e navegue com j, k e Enter.

Terminal
$ sudo snap install clinews
$ clinews

A tradução usa a Google Cloud Translation API e é opcional. Ao usar o atalho pela primeira vez, o app pede sua chave de API e a guarda localmente.
